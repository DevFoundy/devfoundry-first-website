## Review notes

The HTML checkpoint includes hidden control markup used later, as the workbook explains. Its script is a comment and is not connected; there is no finished JavaScript application at that stage. The CSS checkpoint intentionally has a fixed desktop width. The theme reads the system preference on load; it does not listen for live operating-system theme changes. Storage can behave differently for file URLs.

The workbook's request not to upload the full paid-course ZIP belongs to its original packaging. Here the same practical instruction is to publish only the learner portfolio when following Module 6. The PDF is preserved, and the repository is being prepared for free distribution with licensing pending.
