# Getting started

[Course home](../README.md) · [Open the workbook](../course/DevFoundry-Build-and-Deploy-Your-First-Website.pdf)

## Download the files

If you have not used GitHub before, choose **Code → Download ZIP** on this repository's GitHub page. Extract the ZIP before editing. A repository is the project folder and its recorded change history; you do not need to understand Git to begin Module 0.

If you already use Git, copying a repository onto your computer with its history is called **cloning**. Copy the address from GitHub's Code menu and use your preferred Git client. You learn Git commands in Module 5.

## Prepare your working copy

1. Copy the entire `01-starter-files` folder, including its `assets` folder, into a separate location outside the downloaded course folder.
2. Rename the copy `devfoundry-portfolio`.
3. Install [Visual Studio Code](https://code.visualstudio.com/), a modern browser and [Git](https://git-scm.com/downloads). Create a GitHub account for Modules 5 and 6.
4. In VS Code choose **File → Open Folder**, then select your working copy. An editor changes files; a browser displays the result.
5. Open `index.html` in the browser through your file manager. A blank page is expected at the starter stage. Start Lesson 0.1 in the workbook.
6. Save changes in the editor and refresh the browser. Keep the workbook open beside your code.

No Node.js, package installation, framework, bundler or build command is needed. A local preview extension is optional. Theme persistence is best checked on a local preview server or the deployed HTTPS site because browsers handle file URLs differently.

## Use checkpoints when you need them

A checkpoint is a complete example at the end of a stage. Compare the relevant file when stuck, understand the difference, and return to your own working copy. `03-css-complete` intentionally overflows on narrow screens; `04-responsive-complete` fixes it. JavaScript is added in `05-javascript-complete`.

Do not start from `06-final-project` unless you are reviewing the completed solution. Do not copy hidden `.git` folders between working copies.

## Finish and publish

Use the [final checklist](../challenges/final-checklist.md). In Module 5, make your working portfolio a Git repository. In Module 6, publish that portfolio from a separate GitHub repository. The workbook's repository-root instructions refer to **your portfolio repository**, not this multi-folder course repository. See [publishing](publishing.md).
