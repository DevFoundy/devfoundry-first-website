# Responsive complete

**Module 3 and Project 3** · [Course workbook](../course/DevFoundry-Build-and-Deploy-Your-First-Website.pdf) · [Course home](../README.md)

The portfolio adapted to narrow and wide viewports.

## What should work

Fluid container, scaling images, one/two/three project columns, stacked mobile layout, keyboard focus and reduced-motion rules are present. All navigation links stay visible.

## What is not implemented at this stage

JavaScript is not connected. Menu, theme and filter buttons remain hidden; the mobile links stay visible instead of opening with a button.

## Open this checkpoint

Open `index.html` in a browser through your file manager. A local preview extension is optional. No package manager, build tool, environment variables or backend are required.

Work in your own copy of [the starter folder](../01-starter-files/). Use this checkpoint to compare a file when you get stuck. Do not replace working code or copy hidden Git history between checkpoints.

## Example content

Alex Morgan is an example identity, and `alex@example.com` is an explicitly labelled demo address, not a DevFoundry contact. The landing-page and task-app cards are planned concepts. Use honest descriptions and replace demo details before publishing your portfolio. The bundled SVGs are course illustrations.

## Publishing your own portfolio

This README explains a course checkpoint. In Module 5, replace it in your working copy with your own project README, including your features, local opening instructions and actual live URL after deployment. The course links in this checkpoint README depend on the surrounding course folder.

In Module 6, put the **contents of your working portfolio folder** at the root of your own portfolio repository. Then choose `main` and `/ (root)` in GitHub Pages. Do not publish the entire course repository using those student instructions. The finished reference is in [06-final-project](../06-final-project/), not at the course repository root.
