# Practice challenges

[Challenge home](README.md). Try these before opening the answer guide.

## Challenge 1 Content and navigation

Add a “Now learning” section with a heading and paragraph. Link to it from navigation. Pass when the new link moves to that section and its ID is unique.

## Challenge 2 Card spacing

Increase the inside space in every card while preserving equal column widths. Pass when cards fit the same grid without overflow.

## Challenge 3 Responsive layout

Make the tablet layout begin at 700px instead of 640px. What else would you need to change if you wanted the navigation to use the same breakpoint?

Pass when the project grid changes from one column at 699px to two columns at 700px. If you also move the menu breakpoint, its CSS and JavaScript conditions must agree and its keyboard behavior must still work.

## Challenge 4 Interaction

Add an “Other” filter with a matching fourth card. Pass when it shows only matching cards and the status count is correct.

## Challenge 5 Delivery

Make one small content improvement, commit it and prove the public site updated.
