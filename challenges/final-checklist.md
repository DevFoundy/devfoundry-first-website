# Final project checklist

- [ ] My name, page title, metadata and contact details are correct.
- [ ] Navigation, hero, About, Skills, Projects, Contact and footer exist.
- [ ] At least three project cards have honest descriptions and meaningful visuals.
- [ ] Finished links reach real destinations; unfinished work is clearly labelled.
- [ ] Images use correct relative paths, dimensions and alt text.
- [ ] There is no page-level horizontal scrolling at the four test widths.
- [ ] Text remains available at 200% zoom; keyboard focus is visible.
- [ ] The mobile menu opens, closes, handles Escape and survives resizing.
- [ ] Theme state and its accessibility attribute agree; saved choice restores when available.
- [ ] Filtering shows two Web cards, one JavaScript card and all three on reset, or the matching counts for my own categories.
- [ ] All links and project cards remain available without JavaScript.
- [ ] Reduced-motion settings suppress unnecessary card movement.
- [ ] The console has no unexpected errors on the local or deployed page.
- [ ] My repository contains source files, assets, .gitignore and README.
- [ ] My commit history describes real changes and contains no private credentials.
- [ ] My live URL loads and I have verified a content update after deployment.
